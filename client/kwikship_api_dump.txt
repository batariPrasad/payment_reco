The Kwikship Public API allows merchants to programmatically manage orders, track shipments,
and handle NDR (Non-Delivery Report) workflows.

validates credentials against the GoKwik Merchant Service.

Date Ranges
All date range filters have a maximum span of 30 days.
Both dates must be provided together — sending only one date returns an error.
Use ISO-8601 format: 2026-04-01  or 2026-04-01T00:00:00.000Z .
End dates are inclusive — end_date=2026-04-20  includes all records through the end of
April 20th.
For Tracking bulk endpoint, both start_date  and end_date  are required.
Strict Validation
All endpoints enforce strict field validation — unknown or extra fields in request bodies and
query parameters are rejected with a VALIDATION_ERROR  (400).
Only send documented fields to avoid validation errors.
Error Handling
Always check the success  field in the response.
Use error.code  for programmatic error handling, error.message  for display.
Implement retry logic with exponential backoff for 500  errors.
Order Creation
Validate that collectable_amount  is 0  for PREPAID orders.
The billing_address  defaults to shipping_address  and return_address  defaults
to pickup_address  if not provided.
Dimensions are in cm and weight in kg. The API converts internally to mm and grams.
Each order must have at least one item with quantity >= 1.
NDR Actions
Only undelivered  shipments can have NDR actions.
Always provide comments  when taking an action — it helps courier partners.
Use deferred_date  to schedule re-delivery for a future date.
